# full.subsets.gam

Deprecated alias for
[`full_subsets_gam`](https://beckyfisher.github.io/FSSgam_package/dev/reference/full_subsets_gam.md).
Retained because `full.subsets.gam` is used directly in the companion
docs repository's published case studies
(<https://github.com/beckyfisher/FSSgam>), e.g. case-study-2.Rmd. New
code should call
[`full_subsets_gam`](https://beckyfisher.github.io/FSSgam_package/dev/reference/full_subsets_gam.md)
directly.

## Usage

``` r
full.subsets.gam(...)
```

## Arguments

- ...:

  Arguments passed on to
  [`full_subsets_gam`](https://beckyfisher.github.io/FSSgam_package/dev/reference/full_subsets_gam.md).

## Value

See
[`full_subsets_gam`](https://beckyfisher.github.io/FSSgam_package/dev/reference/full_subsets_gam.md).

data(case_study1)

test.fit <- gam(Herbivore.abundance ~ s(depth, k = 3, bs = "cr") + s(site, bs = "re"),

  use.dat = use.dat,
  test.fit = test.fit,
  pred.vars.cont = c("complexity", "depth"),
